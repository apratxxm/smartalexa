## Why reset

Six weeks of source-only fixes, review rounds and offline tests produced zero live-verified commands. The old path (`main.py`) runs; the new path sits behind `listener.async_enabled = false` and `conversation.enabled = false`. Every live test was deferred on RAM. The old Codex thread is ~110 MB, repeatedly compacted, and its own checkpoint says backlog coverage is incomplete.

## The slice

**"Alexa, <music command>" → new capture path → brain (`qwen3:4b-instruct-2507-q4_K_M`) → Spotify adapter → spoken confirmation**, verified by you speaking in the room.

Commands in scope: play <track/artist/album>, pause, resume, next, play <X> at <N>% volume (Windows volume; Spotify stays at 100%, per the user's 23 Sep rule).

Out of scope until accepted: wake retraining, personal wake model, Opera/apps, Windows volume, Codex delegation, answers/retrieval, Jam, any fix to the legacy `main.py` path, Token Tracker.
